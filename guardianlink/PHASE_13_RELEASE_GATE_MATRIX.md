## محدودیت اجرای فعلی

در این نوبت نیز محیط فاقد `gradle`, Gradle wrapper, `docker`, `psql`, `pg_dump`, `pg_restore`, `age`, `aws`, `adb`, `gh`, scannerها و Git repository/remote است. هیچ AWS account/credential، domain، signing key، GitHub repository/environment، database یا test device ارائه نشده. بنابراین گیت‌های runtime و remote با دستور واقعی اجرا نمی‌شوند؛ اجرای source-only workflowها در workspace را به‌عنوان CI run ثبت نکرده‌ام.

## قاعدهٔ تغییر وضعیت

فقط پس از ثبت command/run ID، timestamp، محیط، خروجی واقعی، artifact/checksum یا test evidence مستقل، ردیف از OPEN/BLOCKED به PASSED/FAILED تغییر می‌کند. «workflow تعریف شده»، «تست در source موجود است»، «script parse شد» یا «architecture پیشنهاد شد» برای deploy/security/restore/device gate کافی نیست.
