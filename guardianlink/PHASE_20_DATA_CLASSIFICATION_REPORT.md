# گزارش طبقه‌بندی داده — فاز ۲۰

**وضعیت ممیزی:** `PARTIAL`؛ schema/source inventory انجام شد. دسترسی به DB زنده، deployment، storage و data subject records `BLOCKED BY ENVIRONMENT` است؛ محل‌های زیر از source/config نتیجه شده‌اند، نه از مشاهدهٔ محیط اجرا.

## اصول و نقش‌ها

- «مالک/موضوع داده» در جدول زیر به معنای فرد/خانواده‌ای است که داده دربارهٔ اوست؛ نقش حقوقی Controller/Processor باید با jurisdiction و قرارداد تعیین شود.
- Parent حساب‌دار احراز‌شده کنترل خانواده را دارد؛ Child دادهٔ دستگاه/استفاده/موقعیت موضوع داده است. Device token فقط عملیات device خود را مجاز می‌کند. Backend worker و Admin/support دارای endpoint نقش‌دار در source فعلی شناسایی نشدند.
- هر export/delete باید family/device scope را در Backend اعمال کند؛ UI یا UUID حدس‌پذیر/غیرحدس‌پذیر جای مجوز نیست.
- PostgreSQL/S3/disk encryption در محیط واقعی `NOT TESTED`؛ encrypted backup script فقط طرح اجرایی است. Android SecureStore از AES-GCM/Android Keystore در source استفاده می‌کند؛ Web token فقط memory؛ ترجیح رابط کاربری در localStorage است.
