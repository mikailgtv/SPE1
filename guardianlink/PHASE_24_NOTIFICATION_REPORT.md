# گزارش اعلان‌ها

**تاریخ ارزیابی:** ۶ اکتبر ۲۰۲۶  
**مرزبندی شواهد:** PASS فقط برای فرمان اجراشده؛ مواردی که محیط/دسترسی لازم ندارند BLOCKED و موارد اجرا‌نشده NOT_TESTED هستند. ادعاهای فازهای پیشین سابقه‌اند و به‌تنهایی PASS این فاز نیستند.
تحویل واقعی FCM، اعتبار token، permission/runtime، foreground/background، حذف token، retry و رفتار پس از logout روی سرویس/دستگاه واقعی آزمایش نشد. هیچ پیام آزمایشی ارسال نشده و ادعای delivery نداریم. **NOT_TESTED/BLOCKED**؛ نیازمند credential غیرتولیدی و دستگاه رضایت‌داده است.
