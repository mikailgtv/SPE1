# گزارش SOS

**تاریخ ارزیابی:** ۶ اکتبر ۲۰۲۶  
**مرزبندی شواهد:** PASS فقط برای فرمان اجراشده؛ مواردی که محیط/دسترسی لازم ندارند BLOCKED و موارد اجرا‌نشده NOT_TESTED هستند. ادعاهای فازهای پیشین سابقه‌اند و به‌تنهایی PASS این فاز نیستند.
SOS روی دستگاه واقعی، مجوز/مکان، تحویل API، رسید/تأیید، قطع شبکه، لغو، deduplication و مسیرهای خطا آزمایش نشد. پیاده‌سازی یا وجود endpoint به‌تنهایی تضمین تحویل/ایمنی نیست. هیچ مکان دقیق یا داده شخصی در گزارش ثبت نشده. **NOT_TESTED**.
