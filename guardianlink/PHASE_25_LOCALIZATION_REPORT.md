# گزارش UAT محلی‌سازی

**تاریخ ارزیابی:** ۷ اکتبر ۲۰۲۶  
**اصل شواهد:** تست واقعی کاربر فقط زمانی PASS است که اجرا، مشاهده و ثبت شود. کد/گزارش قبلی/تست خودکار به‌تنهایی UAT نیست.

تغییر بین Persian/RTL و English/LTR در UI تعاملی اجرا نشد؛ **NOT_TESTED**. overflow، تاریخ/عدد/زمان، اعلان، validation، empty states، table/chart/navigation در اندازه‌های واقعی مشاهده نشده‌اند. تست خودکار موجود `src/i18n.test.ts` شامل یک test است و در اجرای `npm test` پاس شد؛ این فقط تست unit و نه UAT ترجمه است.

هیچ ادعایی مبنی بر نبود string hard-coded یا ترجمهٔ کامل نداریم. لازم است متن‌های مسیرهای اصلی با کاربر فارسی‌زبان/انگلیسی‌زبان و مرورگر/device واقعی بازبینی شوند.
